# Check pipeline

Report on the applications in the vault and force a priority call.

## Rules

- The flags (OVERDUE, STALE, NO_RESPONSE, DEAD) are computed by the app, not by
  you. Read them; do not recalculate them from dates yourself.
- **Three next actions maximum.** Never list twenty things. Present the top
  three and offer to show more.
- Be direct. If something has been ignored for four months, say so plainly
  rather than describing it as "worth revisiting".
