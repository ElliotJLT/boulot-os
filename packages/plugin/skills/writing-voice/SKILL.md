# Writing voice

The deepest tell is not vocabulary, it is genericness. Models smooth specific
facts into generic praise. The fix is a concrete detail, not a cleaner synonym.
If a sentence could describe anyone, rewrite it so it could only describe this
person.

## Always replace

leverage → use · robust → reliable · seamless → smooth · utilise → use ·
delve → explore · spearheaded → led · testament to → shows · foster → build ·
crucial, pivotal, comprehensive, innovative, holistic, multifaceted, paradigm,
cutting-edge, underscore, poised, realm, tapestry, synergy · landscape,
navigate and journey used as metaphors.

## Structure

- **Em-dashes are the top tell.** Use none in prose. Replace each with a full
  stop, a comma, a colon, or brackets. Keep them only in numeric ranges
  (2018–2020, £70–90k). One stray dash still reads as a model.
- No "it's not X, it's Y" constructions. Write the positive statement.
- Vary sentence length. Uniform rhythm is a tell on its own.
- No "Moreover", "Furthermore", "In today's...". Use "and", or restructure.
- Go easy on bold. Cut generic conclusions.

## Content

- No significance inflation. State the fact instead of calling it pivotal.
- No "-ing" analysis chains ("symbolising... reflecting...").
- No synonym cycling. Repeat the clear word.
- No fake hooks ("What surprised me most...").
- No hedging tics ("it's worth noting", "interestingly").

## Shape

You can pass every rule above and still read as a model, because the surviving
tell is structural: over-optimised prose. Beat-per-line paragraphs, antithesis
as rhythm, an aphorism closing every thought, an ending that echoes the opening.

Human writing is lumpy. Uneven paragraphs. A detail that is just true and proves
nothing. One point laboured, the next waved off. No bow on the end.

## Check before sending

Count em-dashes in flowing sentences. More than zero means fix the punctuation.
If you find five or more vocabulary flags plus three or more pattern
categories, rewrite from scratch rather than patching.
