# Application Answer Rules

## Before writing a single word
1. Research what the company screens for. Search for recruiter interviews, hiring guides, founder quotes on culture. Understand specific signals, not generic "show passion."
2. Map the candidate's experience to those signals.

## While writing
3. Apply the swap test: can you replace the company name with a competitor and the answer still works? If yes, rewrite. Must contain something only true about THIS company, framed through the candidate's experience.
4. Don't parrot the company's achievements back at them. Frame their decisions through what the candidate has learned from their own work.
5. Run the anti-AI check DURING writing (see ai-writing.md rules). Don't write AI text then sand it off.
6. No Hollywood lines. Write like a smart person typing an important email.

## Process
Research first, write once. One draft, not nine. Use sub-agents for research, not for writing competing drafts.
