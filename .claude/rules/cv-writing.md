# CV Writing Rules

Every CV draft must be checked against the JD before presenting it as done.

## Process
1. List every requirement from the JD (explicit and implicit)
2. Map each one to a specific CV bullet from cv-master.md
3. If a requirement has no match — either reframe existing experience to hit it, or flag the gap explicitly
4. Don't let real experience go unmentioned. If the candidate did it, find the bullet where it belongs.
5. Present the mapping table (JD requirement | CV evidence | Hit/Gap) before saying a CV is ready

## Constraints
- NEVER fabricate experience. Only rearrange, emphasise, and reword existing bullets.
- Check references/ for structural examples of CVs that landed interviews.
- Output markdown first for review, generate PDF on request via /cv-generator skill.
